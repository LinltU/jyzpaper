# experiment.xlsx 双类别条件扩散大规模增强报告

## 1. 任务定义

本次只使用 `experiment.xlsx` 工作表镜像数据。目标是：

```text
error=0       正常绝缘子串
error!=0      存在零值绝缘子
```

本次同时生成两类数据：

- 正常类：`error=0`；
- 异常类：`error!=0`，统一作为二分类异常，不生成具体片号标签。

合成样本只在训练集内生成，最终评价使用未参与生成训练的真实实验窗口。

## 2. 数据协议

窗口长度为 6，两个设备按最近时间戳配对，不跨越不同 `error` 阶段。模型输入特征为：

```text
M4, M7, Temp_shared, Hum_shared,
Mdiff, Mratio, logratio, elapsed_min
```

条件变量为：

```text
abnormal_flag
experiment_date
Temp_shared
Hum_shared
HumidityTrend
TempTrend
```

其中 `abnormal_flag` 只用于离线条件生成，部署检测时不能使用真实 `error`。

## 3. 生成规模

训练/测试按日期和 `error` 阶段分层切分：

| 数据 | 窗口数 |
|---|---:|
| 真实训练窗口 | 470 |
| 其中正常窗口 | 432 |
| 其中异常窗口 | 38 |
| 真实测试窗口 | 124 |
| 测试中异常窗口 | 15 |

大规模增强设置：

```text
正常类：训练正常窗口 × 4 = 1728 个
异常类：训练异常窗口 × 20 = 760 个
合计：2488 个合成窗口
```

因此异常样本从 38 个扩展到 760 个，正常样本从 432 个扩展到 1728 个。

## 4. 模型方案

### 4.1 直接条件 DDPM

扩散模型直接对 8 个特征组成的 6 步窗口进行建模，条件包括类别、日期和共享环境状态。

### 4.2 NsDiff 风格条件 DDPM

在扩散训练前对每个特征做局部均值/尺度归一化，目标是减少不同日期测量水平差异，再进行条件生成。

两种方案都使用 20 个扩散步、160 个训练 epoch，并采用同一套训练/测试切分。

## 6. 结果解释

大规模生成成功完成，但当前没有提升真实实验窗口上的分类效果：

1. 合成数据数量明显增加，但平衡准确率反而下降；
2. 直接 DDPM 的 AUROC 尚能保持，但分类阈值和类别边界变差；
3. NsDiff 风格在大规模扩增后 AUROC 也出现下降；
4. 原因主要是异常训练样本只有 38 个，模型会重复学习少量异常阶段的局部模式，并生成过度集中的异常样本；
5. 合成正常样本和合成异常样本的联合分布仍不能完全覆盖真实双设备关系；
6. 训练集内的条件标签可以帮助生成类别，但不能保证生成样本具有真实物理一致性。

因此，“生成更多数据”不等于“增加更多有效信息”。当前生成的 2488 个窗口可以作为研究数据或压力测试数据，但不建议直接全部加入正式检测模型。

## 7. 与前一版正常残差扩散的关系

前一版只生成 29 个正常残差样本，用于扩展 Mahalanobis 正常分布，指标基本不变。本次扩大到 2488 个窗口，并同时生成正常和异常两类，结果显示：

```text
少量正常残差增强：不提升，但不明显破坏基线
大规模正常+异常增强：数量增加，但真实测试效果下降
```

## 8. 当前建议

当前可以保留这些合成数据用于：

- 检查扩散模型是否学习到双设备关系；
- 训练过程压力测试；
- 后续物理一致性筛选实验；
- 与真实异常窗口做分布可视化比较。

当前不建议：

- 直接把 2488 个合成窗口全部加入最终检测器；
- 使用合成异常数据替代真实 `error!=0` 实验数据；
- 通过增加生成数量来弥补异常样本种类不足。

下一步应增加生成样本筛选：

```text
条件扩散生成
    ↓
温湿度范围检查
    ↓
M4/M7、差值、比例联合分布检查
    ↓
Mahalanobis 正常/异常物理一致性筛选
    ↓
只保留可信合成样本
```

本轮结论是：已经实现并测试了同时生成正常和异常的大规模条件扩散增强，但在当前 `experiment.xlsx` 样本规模下，未经筛选的合成数据没有带来有效提升。
