# 温湿度分阶段 + P10/P50/P90 条件区间复测

## 1. 方法

针对之前实际挂线数据采用的“环境条件正常区间”思路，本次在 `experiment.xlsx` 上实现了一个本地对照：

```text
共享温度、共享湿度、温湿度趋势、经过时间
        ↓
按每个实验日期的正常稳定湿度分位点划分低/中/高湿阶段
        ↓
分别学习 M4/M7 正常残差的 P10、P50、P90
        ↓
测试值落在 P10-P90 之外时增加异常分数
        ↓
用 error!=0 真实实验标签评估
```

## 2. P10/P50/P90 在这里的含义

- P10：给定温湿度和趋势条件下，正常 Measure 残差的第10百分位；
- P50：正常残差的中位水平；
- P90：正常残差的第90百分位。

如果测试残差低于 P10 或高于 P90，说明它偏离正常环境条件下的常见区间。

该方法不是把 P10/P50/P90 当作固定全局阈值，而是随温度、湿度、趋势和湿度阶段变化的条件区间。

## 4. 结果解释

温湿度分阶段后，确实能够建立“在当前环境条件下 Measure 是否正常”的关系，且比简单的 D3R 去趋势方案更好：

- 精确率约 77.19%；
- 召回率约 74.03%；
- 正常误报率约 1.89%。

但在当前实验数据上仍低于双设备联合 Mahalanobis。主要原因是：

1. 250626 的湿度区间约为 66.5–69.9%，其他日期主要为 45–55%，湿度阶段与实验日期高度混杂；
2. 每个日期稳定正常样本量较少，分阶段后每个阶段的样本更少；
3. P10/P90 只能表达单个 Measure 残差的区间，Mahalanobis 能同时表达 M4、M7、差值和比例的联合相关性；
4. 温湿度可能存在阈值、滞后或上电状态影响，简单分段还不够。

## 5. 对实际挂线思路的结论

这个方向是可行的，但建议把它作为 Mahalanobis 的环境解释层，而不是完全替代双设备联合检测：

```text
环境条件模型：P10/P50/P90
        +
双设备联合残差：Mahalanobis
        ↓
环境偏离分数 + 双设备关系偏离分数
        ↓
最终报警
```

下一步最有价值的是补充相近温湿度下的正常和 `error!=0` 实验，使模型能够区分：

```text
温湿度导致的 Measure 变化
```

和：

```text
零值绝缘子导致的额外偏离
```
