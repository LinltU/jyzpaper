## 3. 对小白解释新的预测值是什么

在说明中先用一句话解释：

> 在还没有把当前 Measure 告诉模型前，根据该设备过去已经观测到的序列，以及当前可获得的温湿度等条件，估计这次 Measure 应该是多少；随后才用实际值减去这个估计值。

明确任务是 **当前时刻温湿度已观测条件下的 Measure 条件预测/检测**，不是声称提前知道未来天气。当前 `Temp_t, Hum_t` 可用，前提是它们在当前检测时刻真实可获得；当前 `Measure_t` 仅作为训练标签、预测完成后的残差及检测证据。若尝试真正提前预测，不能使用未获得的未来实测温湿度，须另做版本。

按以下关系实现：

```text
历史窗口 X_t = 设备在 t 之前的 L 条有效历史观测
当前条件 c_t = 当前 Temp、Hum、可获得的时间信息、与最后观测的真实时间差
预测值 yhat_t = 修正 DLinear(X_t, c_t)
残差 e_t = Measure_t - yhat_t
```

正残差表示比模型预期高，负残差表示比模型预期低；是否对应实际故障机理须另有电气知识和检修证据，不能将所有正偏差自动命名为某类故障。

## 4. 模型结构与条件注入的默认实现

先实现一个可解释且规模适合小数据的 **带环境条件的 DLinear 变体**，区分标准 DLinear 和本项目扩展，不要把附加 MLP 都称为原始 DLinear。

可参照作者实现：
`https://github.com/cure-lab/LTSF-Linear/blob/main/models/DLinear.py`

默认一阶目标为 `pred_len=1`：

1. 输入 `[B,L,C]`；历史通道至少包括 `Measure, Temp, Hum`，记录各通道的时间与缺测掩码。
2. 只在这个完全位于预测时刻之前的窗口内部，沿 L 维移动平均：
   `T = MovingAverage(X)`，`S = X - T`。
3. 分别沿时间维用线性映射 `L → 1` 预测趋势与剩余分量，相加后以线性通道融合输出 Measure。核验通道顺序和输出形状。
4. 以独立的线性条件支路加入当前标准化 `Temp_t, Hum_t`、交互项 `Temp_t×Hum_t`、elapsed、距最后观测的小时数，以及时间差/掩码摘要：
   `yhat_t = yhat_history_t + Linear(phi(c_t))`。
5. 不把当前目标、不由当前目标计算的统计量、不在该时刻可用的同串未来值送进条件支路。主基线不以当前 peer Measure 为预测输入，让同串比较保留独立证据作用。
6. 默认每设备建模，样本不足时不要偷偷用全历史补充。可提供共享模型作为明确的备用方案，但其训练必须服从全体设备统一时间截止，保存设备/组编码和来源范围。

时间序列不等间隔时，按观测顺序形成 DLinear 历史窗口只是明确近似，不等同于固定小时网格 DLinear。主实现保留真实时间差作为条件并标明该近似；不做跨长缺口的双向插值。若增加规则网格版本，只允许预测时刻之前的填补，记录观测掩码、数据年龄及重采样规则，作为另一个消融，不混入主结果。

小型超参数候选建议：`L∈{8,16,32}`，奇数平滑核 `k∈{3,5,7}` 且 `k≤L`，学习率 `{1e-3,3e-4}`；先用固定种子 42 选型，再以 2026、2027 检查稳定性。控制搜索规模，使用验证集 MAE 选择，不按候选异常数量或“图上看起来好”选择。

损失可用 SmoothL1；early stopping 仅用验证期。明确优化器、最大 epoch、patience、batch size、输出约束和缺测策略。无物理依据不强加 Softplus，不把非负测量假设当作事实。标准化在训练期拟合，反标准化后计算原始单位预测误差。

## 7. 湿度分层、尺度与阈值只能从独立校准期学习

## 8. 异常区域定义和 v4 的可比性

主区域仍按每设备完整观测顺序形成原 v4 的 32 点无重叠窗口 ID，尾部 2–31 点保留，单点尾部不可评估。窗口不可跨过模型折/训练校准评估边界后再混算：跨边界窗保留原 ID，并标 `split_boundary` 不纳入主评估；附表列清丢失覆盖，不能偷偷改变窗口起点。

- B：同窗至少 2 个有效不同步跳变≥8。
- C：同窗至少 1 个有效不同步跳变≥12。
- D：没有物理 peer 时，残差超限占比≥0.15、绝对残差90分位≥2，且残差跳变≥2.5的点至少2个。

保留跳变基本定义：

```text
J_t = |d_t - d_(t-1)| / (sqrt(2) × scale_C(d))
```

scale_C 由本设备 C 参考水平量计算并冻结，不是差分尺度，也不是除以时间后的导数；缺口/peer 集合规则按上节执行。D 规则残差跳变同样明确分子、分母及校准来源。

## 9. 预测评估、候选核验和解释

在 D 真实预测值上报告 MAE、RMSE、平均有符号误差；按设备、电压、湿度层、采样节奏、预测间隔分层，注明有效样本数和覆盖率。各模型只在共同可评估时间点比较，另报各自覆盖率。不要把训练误差与测试误差混在一起。

没有真实异常标签，不能报告真实故障准确率、召回率、F1 或声称临床式置信度。可报告：

- 候选窗口/点占比、不可评估占比、连续候选事件数量、事件真实时长。
- 不同随机种子和合理参数下标签稳定性、Jaccard、共同覆盖范围。
- 高湿与低湿候选率、peer 缺测/时间偏差分布、长缺口与 peer 切换关联。
- 预先设计的合成偏移/漂移/尖峰/共同变化注入，只用于已冻结流程的受控实验，结果单列，不能替代真实验证或用于回调 D 阈值。

详细列出 9231、9355、9421、0603 以及 110kV 8878、9867 的代表阶段：实际值、DLinear 预期值、残差、温湿度、peer 时间偏差、同串原始差、跳变、有效证据和触发规则。解释为何标红、为何取消 v4 标红、以及哪些变化只因对齐/覆盖不足。没有候选也须给出量化证据。

DLinear 使用过去 Measure，可能跟随缓慢退化。保留冻结参考模型，并绘制环境-only Huber 参照、DLinear 趋势及持续同串差；不能仅因 DLinear 残差小就认定正常。除非有确认健康参考，不能称其为“健康基线”。短期预测精度更好不自动等于异常检测更好。

## 11. 必须通过的验收

1. 源文件哈希不变；每条有效原始观测有唯一追踪记录，无静默删点。
2. 特征与标准化不读取当前目标或未来目标，训练/验证/校准/测试职责分离。
3. 修改待预测点的 Measure 后重建该点输入，其输入和预测必须保持不变；该点残差应相应变化。修改某决策时刻之后的 Measure，不得影响该时刻已经产生的预测或标签；窗口区域判定以窗口结束的决策时刻为准。
4. 时间序列维为真实 L>1；非恒定模拟序列的分解剩余项不能因维度错误恒为零；训练推理特征一致。
5. 主 peer 匹配满足 `peer_timestamp≤target_timestamp`；从原时间独立算出的偏差与存储值一致，全部接受点满足逐点容差，自身从不参与。
6. NaN 不补零，不跨缺测、规定长缺口或 peer 切换构造主跳变。
7. 所有 D 变换及阈值参数来自允许的过去校准数据，修改 D 未来数据不能改变已经产生的标签；rank/CDF 不在 D 重拟合。
8. 每个标签能追溯到预测、校准参考、peer、窗口和具体规则；候选整窗点映射一致，直接触发点单列。
9. v4 对照使用时间修正版；所有方法只在共同可评估区间比较，变化原因分解，不以候选数“达标”。
10. 表格、图像、汇总互相一致，图中没有虚构观测或未校准概率。
