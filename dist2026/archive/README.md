# 历史归档

本目录只保存已完成实验的产物，不参与当前 GUI 或最新模型运行。

| 目录 | 内容 |
|---|---|
| `legacy_models_202604/` | 2026 年 4 月生成的 17 个根目录 `.pth` 模型 |
| `legacy_results_202604/` | 2026 年 4 月的 43 个预测、比较 CSV 和日志 |
| `comparison_experiments_202607/` | 2026 年 7 月特征、湿度阶段和早期扩散对照实验，共 17 个目录 |
| `generated_cache/` | 可重新生成的 Python 缓存 |
| `legacy_code/` | 早期训练入口、DLinear 对照脚本和 `test.py` 旧流程 |
| `legacy_tests/` | 早期 FMLP/LTSF/Transformer 对照测试脚本 |

这些文件采用移动归档，没有删除。早期脚本重新运行时仍会在 `dist2026` 根目录生成新的同名结果。
